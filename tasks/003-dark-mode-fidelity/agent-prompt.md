# Task 003: Improve Dark Mode Fidelity

Mira already supports dark-mode color tokens, but the dark experience should feel intentionally designed — not simply inverted.

Improve dark mode across Mira so it remains quiet, warm, editorial, readable, and restrained.

## Constraints

- Preserve Mira's product principles: quiet, editorial, warm, restrained, human, native to iOS.
- Improve dark-mode readability, surface contrast, borders, and accent harmony.
- Keep light mode unchanged or minimally changed.
- Prefer refining `MiraColors` and existing design-system primitives over changing every screen.
- Do not use raw one-off colors in screens/components.
- Do not add a theme picker, settings persistence, onboarding, or unrelated features.
- Avoid pure black/white, neon colors, unnecessary gradients, or generic SaaS dark-mode styling.

## Product Context

Read Mira's product principles before making changes:

```text
Mira/docs/product-principles.md
```

Mira should feel like a calm journaling app in both light and dark mode. The goal is not more visual drama; the goal is a darker palette that still feels warm, comfortable, readable, and made by the same team.

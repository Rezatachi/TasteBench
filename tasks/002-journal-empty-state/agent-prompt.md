# Task 002: Add an Empty State to Journal

The Journal screen currently feels empty when there are no entries.

Add an empty state that encourages the user to write their first reflection.

## Constraints

- Keep the tone calm and human.
- Do not use generic copy like "No items found".
- Include a primary action to create a new entry.
- Use existing typography, spacing, and button styles.
- The empty state should feel like part of Mira's product language.

## Product Context

Read Mira's product principles before making changes:

```text
Mira/docs/product-principles.md
```

Mira should feel quiet, editorial, warm, restrained, human, and native to iOS. This task is not about adding more features; it is about designing a sensitive non-happy path with product care.

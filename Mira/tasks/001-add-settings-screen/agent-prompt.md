# Task 001: Add a Settings Screen

Users need a place to manage preferences without disrupting the quiet, reflective tone of Mira.

Add a Settings entry point from the Today screen.

The Settings screen should include:
- Profile row
- Appearance preference
- Notification preference
- Privacy section
- Sign out button

Constraints:
- Use the existing design tokens
- Preserve Mira’s calm editorial feel
- Do not introduce new colors unless necessary
- Navigation should feel native to iOS
- Avoid overbuilding
- Do not add persistence, accounts, authentication, or notification scheduling
- The result should look intentional, not generated

After implementation:
- Make sure the app builds
- Do not implement unrelated features
- Summarize files changed and decisions made

This is the first real test.

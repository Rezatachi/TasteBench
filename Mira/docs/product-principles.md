# Mira Product Principles

Mira is a calm journaling app for daily reflection.

The interface should feel:
- quiet
- editorial
- warm
- restrained
- human
- native to iOS

Mira should avoid:
- generic SaaS UI
- loud colors
- unnecessary gradients
- overbuilt settings
- too many abstractions
- dense screens
- clever UI that distracts from writing

Product decisions should prioritize:
1. Reflection over productivity
2. Calm hierarchy over feature density
3. Familiar iOS patterns over novelty
4. Reusable design tokens over one-off styling
5. Human copy over generic system copy
6. Restraint over completeness

A change is successful when it feels like it was designed by the same team that built the original app.
